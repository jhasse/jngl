Detailed Description

A key on the keyboard: one without a character, e.g.

jngl::key::F1, or the one that types a character, e.g. Q or Ö

Unlike for jngl::keyDown(const std::string&), Shift doesn't matter: ‘jngl::Key('q’)is the same key asjngl::Key('Q')`. That makes it something to store, e.g. the key the user has chosen for an action, see toString() and jngl::keysPressed().

Example:

jngl::Key jump = jngl::key::Space;
if (choosing) {
if (const auto keys = jngl::keysPressed(); !keys.empty()) {
jump = keys.front();
choosing = false;
}
} else if (jump.pressed()) {
player.jump();
}
