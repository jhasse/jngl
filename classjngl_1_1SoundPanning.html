Detailed Description

A sound which can be positioned in the stereo field.

Returned by SoundFile::playWithPanning and SoundFile::loopWithPanning. The sound only starts playing once setPanning has been called for the first time, so that it never starts at the wrong position.

The sound is tied to the lifetime of this object: Destroying it (or assigning another SoundPanning to it) stops the sound. This makes it a good fit as a member of an entity in your game world.

Example:

class Enemy {
public:
Enemy() : engineSound(jngl::SoundFile::get("sfx/engine.ogg")->loopWithPanning()) {}
void step() {
// ... move the enemy ...
engineSound.setPanning(position.x / jngl::getScreenSize().x * 2);
}
private:
jngl::Vec2 position;
jngl::SoundPanning engineSound; // stops when the Enemy gets destroyed
};

Member Function Documentation

◆ setPanning()

void setPanning ( float panning)

Set the stereo position, the first call starts playing the sound.

Parameters
panning-1.0f = left, 0.0f = center, 1.0f = right. Values outside of [-1, 1] will be clamped.

Like with a real head, the channel further away from the sound source gets quieter (-10 dB at ±1) and slightly delayed. This can be called every frame, e.g. to follow a moving object. Changes are smoothed, so a fast moving sound will also get a slight Doppler effect.

Once the sound has finished playing (or has been stopped) this does nothing.
