JNGL is a versatile multi-platform library for game development, written in modern C++. It has been used to create several different games on a number of different platforms.

Games using JNGL have been released on Windows, Linux, Mac, iOS, Android and Nintendo Switch1, as well as the browser via Emscripten. There also has been work done on porting games to XBox and Playstation.

⚙️Features

  • C++17
  • zlib License, so suitable for commercial use and static linking
  • OpenGL (ES) 3.0 accelerated
  • PNG, BMP and WebP image support
  • Ogg Vorbis audio support with support for effects like pitch shifting
  • Theora video playback support
  • UTF-8 text output using FreeType
