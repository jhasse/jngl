Detailed Description

Measures how long the GPU takes for what's drawn between start() and stop(), e.g.

a frame, without waiting for it to finish: a measurement comes in a few frames later, see poll().

Needs OpenGL 3.3's timer queries, which OpenGL ES and WebGL don't have. Without them, see isSupported(), start() and stop() do nothing and poll() never returns anything.

Example:

timer.start();
scene.draw();
timer.stop();
while (const auto duration = timer.poll()) {
// a frame some time ago took *duration on the GPU
}
